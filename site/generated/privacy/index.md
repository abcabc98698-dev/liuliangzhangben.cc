# 隐私政策与数据安全声明

1. **零服务端存储**：本站为纯静态站点，没有后端数据库，不设置用户注册系统，不收集、不存储、不上报任何用户的个人用量明细或设备凭证。
2. **浏览器沙箱与本地存储**：账本数据仅保存在您当前浏览器的内存中；若您主动开启“本地持久化”，数据将存储于您本地的 localStorage 或 IndexedDB 中，清除浏览器缓存即可彻底销毁。
3. **防注入与清洁导出**：所有 CSV 导出均经过防公式注入转义，转介主站的链接绝不携带任何私密参数。
