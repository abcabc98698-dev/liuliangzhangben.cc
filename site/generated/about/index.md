# 关于流量账本 (liuliangzhangben.cc)

流量账本是一个专注于解决**“用了多少、怎么扣量、什么时候重置、是否够用、账单为什么不同”**的独立计量与对账知识工具站。

- **分站定位**：纯静态客户端独立运行，所有账本保存在用户浏览器本地，绝不收集个人网络隐私。
- **与主站关系**：唯一选购转化主站为[机场榜一 (jichangbang.org)](https://jichangbang.org)。当用户明确各项用量指标后，可前往主站比对真实服务套餐。
